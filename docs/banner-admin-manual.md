# 홈 배너 관리하기 (운영진용)

사이트 **메인 화면 맨 위에서 넘어가는 슬라이드 배너**는 노션 「배너」
데이터베이스에서 관리합니다. 이미지·문구·링크·순서까지 전부 노션에서 바꿀 수 있어요.

> 반영까지 **최대 5분** 걸립니다. 바꾸고 나서 사이트가 그대로면 조금 기다렸다가
> 새로고침해 주세요.

배너는 **5초마다 자동으로 넘어가고**, 좌우 화살표나 손가락 스와이프로도 넘길 수
있습니다. 등록된 배너가 하나면 넘어가지 않고 그 한 장만 고정으로 보입니다.

다른 데이터베이스 안내: [가이드](./guide-admin-manual.md) · [스밍리스트](./streaming-admin-manual.md)

---

## 1. 새 배너 올리기

1. 「배너」 DB에서 **+ 새로 만들기**
2. `이름` 칸에 **노션에서 알아볼 이름**을 적습니다 (예: `2월 컴백 D-7`)
   → 이 이름은 **사이트 화면에는 안 나옵니다.** 우리끼리 구분하는 용도예요
3. `이미지` 칸에 배너 이미지를 드래그해서 올립니다
4. 필요하면 `링크`·`타이틀`·`설명`을 채웁니다
5. 끝. 5분 안에 사이트에 반영됩니다

### 칸 설명

| 칸 | 꼭 필요한가 | 무엇을 넣나 |
|---|:--:|---|
| `이미지` | ✅ * | 배너 배경 이미지. **첫 번째 파일만** 사용됩니다 |
| `배경색` | ✅ * | 이미지가 아직 없을 때 대신 깔 색 |
| `링크` | | 배너를 눌렀을 때 이동할 주소 |
| `타이틀` | | 배경 위에 겹쳐 나오는 큰 글씨 |
| `설명` | | 타이틀 아래 작은 글씨 |
| `이름` | | 노션에서 행을 알아보기 위한 이름 (화면에 안 나옴) |

\* `이미지`와 `배경색` 중 **하나는 반드시** 있어야 합니다. 둘 다 비면 그 배너는
사이트에 나오지 않습니다.

---

## 2. 이미지 만들 때

- **가로로 긴 이미지**를 준비해 주세요. 모바일에서는 `16:9`, PC에서는 `21:9` 비율로
  잘려 보입니다
- 화면 크기에 맞춰 **위아래가 잘릴 수 있으니**, 중요한 문구나 얼굴은
  **가운데 쪽에** 두는 편이 안전합니다
- 파일 이름·형식·용량은 신경 쓰지 않으셔도 됩니다. 원본 그대로 올려주세요

### 문구는 이미지에 넣을까, `타이틀` 칸에 넣을까

둘 다 됩니다. 편한 쪽으로 하세요.

| | 이렇게 하면 |
|---|---|
| 이미지에 문구가 이미 박혀 있다 | `타이틀`·`설명`을 **둘 다 비웁니다** → 이미지만 깔끔하게 나옵니다 |
| 배경 이미지만 있다 | `타이틀`·`설명`에 글을 적습니다 → 이미지 위에 겹쳐서 나옵니다 |

`타이틀`·`설명`을 쓰면 글씨가 잘 보이도록 이미지 아래쪽에 **어두운 그라데이션이
자동으로 깔립니다.** 따로 어둡게 가공해서 올리지 않으셔도 돼요.

---

## 3. 링크 걸기

`링크` 칸에 주소를 넣습니다.

| 이렇게 적으면 | 이렇게 동작합니다 |
|---|---|
| `https://twitter.com/...` | **새 탭**으로 열립니다 (외부 사이트) |
| `/guide/streaming` | 사이트 **안에서** 이동합니다 (슬래시로 시작) |
| 비워둠 | 눌러지지 않는 배너가 됩니다 |

---

## 4. 이미지가 아직 없을 때 — `배경색`

이미지를 못 구했는데 배너는 띄워야 할 때, `배경색` 칸에 색만 적으면 색 배경으로
배너가 나옵니다. 아래 형태를 전부 알아들어요.

```
#00BFFF      00BFFF      #0bf      skyblue      rgb(0, 191, 255)
```

- **`이미지`가 있으면 `배경색`은 무시됩니다.** 배경은 하나뿐이니까요
- 알아볼 수 없는 값을 적으면 기본 하늘색이 깔립니다
- **글자색은 신경 쓰지 않으셔도 됩니다.** 배경이 밝으면 남색, 어두우면 흰색으로
  자동으로 골라줍니다

---

## 5. 순서 바꾸기

**먼저 만든 배너가 앞에 옵니다.** 새로 만든 배너는 항상 맨 뒤에 붙어요.

> ⚠️ **줄을 위아래로 드래그해도, 뷰 정렬(Sort)을 걸어도 사이트 순서는 바뀌지
> 않습니다.** 노션이 「끌어서 옮긴 순서」를 사이트에 알려주지 않기 때문입니다.
> 노션 화면과 사이트 순서가 다를 수 있으니, 사이트 기준은 **만든 순서**라고
> 기억해 주세요.
>
> 순서를 꼭 바꿔야 하면 개발자에게 `순서` 숫자 칸 추가를 요청해 주세요
> (가이드·스밍리스트 DB가 쓰는 방식입니다).

---

## 6. 배너 잠시 내리기

**줄을 지우지 마세요.** `이미지`와 `배경색`을 **둘 다 비우면** 그 배너만 화면에서
사라집니다. 나중에 이미지를 다시 올리면 그대로 돌아와요.

컴백처럼 매번 돌아오는 배너는 이렇게 재워두면 다음에 이미지만 갈아 끼우면 됩니다.

---

## 7. 이것만은 하지 말아 주세요

아래 세 가지는 **홈 배너 영역이 통째로 빈 채로 나오게** 만듭니다.

| 하면 안 되는 것 | 왜 |
|---|---|
| 칸(속성) 이름 바꾸기 — `이미지`, `타이틀`, `설명`, `링크`, `배경색` | 사이트가 이 이름으로 내용을 찾습니다 |
| 「배너」 DB 자체를 삭제하거나 다른 곳으로 옮기기 | 연결이 끊어집니다 |
| DB 뷰에 정렬(Sort) 걸기 | 노션에서 보이는 순서와 실제 순서가 달라집니다 |

줄을 추가·삭제·수정하는 건 괜찮습니다. 배너는 가이드와 달리 공유되는 개별 주소가
없어서, 지웠다 다시 만들어도 끊길 링크가 없어요. 다만 **다시 만든 줄은 맨 아래로
가니까 순서만 확인**해 주세요.

---

## 안 될 때 확인할 것

**배너가 하나도 안 나와요**
→ 모든 줄의 `이미지`·`배경색`이 비어 있지 않은지 확인해 주세요. 그래도 안 되면
   개발자에게 알려주세요 (DB 연결이 끊겼을 수 있습니다).

**특정 배너만 안 나와요**
→ 그 줄의 `이미지`가 비어 있고 `배경색`도 비어 있는 경우입니다.

**이미지를 바꿨는데 그대로예요**
→ 5분 기다린 뒤 새로고침. 그래도 안 되면 강력 새로고침
   (`Ctrl`+`Shift`+`R`, 맥은 `Cmd`+`Shift`+`R`).

**순서를 바꿨는데 그대로예요**
→ 줄을 드래그해도 사이트 순서는 바뀌지 않습니다(위 「5. 순서 바꾸기」 참고).
사이트 순서는 **배너를 만든 순서**입니다.

**글씨가 배경에 묻혀서 안 보여요**
→ 배경 이미지가 너무 밝거나 복잡한 경우입니다. 문구를 `타이틀` 칸 대신 이미지에
   직접 넣는 편이 낫습니다.
