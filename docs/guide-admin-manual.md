# 가이드 관리하기 (운영진용)

사이트의 **가이드 페이지**(`/guide/…`)에 나오는 이미지와 목록은 전부 노션
「가이드」 데이터베이스에서 관리합니다. 노션에서 바꾸면 사이트에 자동으로 반영돼요.
개발자에게 요청하거나 기다릴 필요 없습니다.

> 반영까지 **최대 5분** 걸립니다. 바꾸고 나서 사이트가 그대로면 조금 기다렸다가
> 새로고침해 주세요.

다른 데이터베이스 안내: [배너](./banner-admin-manual.md) · [스밍리스트](./streaming-admin-manual.md)

---

## 1. 이미지 교체하기 (제일 자주 하는 일)

예를 들어 「멜론」 스트리밍 가이드를 새 버전으로 바꾼다면:

1. 노션 「가이드」 DB에서 **멜론** 줄을 클릭해 엽니다
2. `이미지` 칸에서 **기존 이미지를 삭제**합니다
3. 새 이미지 파일을 **드래그해서 올립니다**
4. 끝. 5분 안에 사이트에 반영됩니다

**줄을 지우고 새로 만들지 마세요.** 반드시 기존 줄을 열어서 이미지만 바꿔주세요
(이유는 [6번](#6-줄을-지우고-다시-만들지-마세요) 참고).

### 신경 쓰지 않아도 되는 것들

- **파일 이름** — 뭐든 상관없습니다. 한글·공백·날짜 다 괜찮아요
- **파일 형식** — JPG, PNG 그대로 올리시면 됩니다
- **파일 용량** — 줄이지 않으셔도 됩니다. 원본 그대로 올려주세요
  (사이트가 알아서 가볍게 바꿔서 보여줍니다)
- **올리는 순서** — 지웠다 다시 올려도, 몇 번을 반복해도 괜찮습니다

디자이너에게 받은 파일을 **손대지 말고 그대로** 올리시면 됩니다.

### 이미지가 여러 장일 때

`이미지` 칸에 여러 장을 올리면 **올린 순서대로** 사이트에 표시됩니다.
순서를 바꾸고 싶으면 노션에서 파일을 드래그해 옮기면 됩니다.

## 2. 새 가이드 추가하기

1. 「가이드」 DB에서 **+ 새로 만들기**
2. 아래 3개는 **꼭** 채워주세요

   | 칸 | 무엇을 넣나 | 예시 |
   |---|---|---|
   | `제목` | 카드에 표시될 이름 | `애플뮤직` |
   | `섹션` | 어느 페이지에 넣을지 (드롭다운) | `음원 스트리밍` |
   | `상태` | 공개할 준비가 됐는지 | `오픈예정` |

3. `이미지` 칸에 파일을 올립니다
4. 준비가 끝나면 `상태`를 **공개**로 바꿉니다

### 나머지 칸 (선택)

- `설명` — 카드에 작게 들어가는 한 줄 설명. 비워도 됩니다
- `플랫폼` — 카드에 붙는 플랫폼 아이콘. 목록에 없는 플랫폼은 개발자에게 요청해 주세요
- `순서` — 같은 섹션 안에서 몇 번째로 보일지. 비우면 맨 뒤로 갑니다

### `섹션` 드롭다운과 노출 페이지

| 고른 선택지 | 사이트에서 나오는 곳 |
|---|---|
| `음원 스트리밍` · `MV 스트리밍` | 스트리밍 가이드 |
| `아이디 생성` | 아이디 생성 가이드 |
| `음악방송 투표` · `시상식 투표` | 투표 가이드 |
| `음원 다운로드` · `MV 다운로드` | 다운로드 가이드 |
| `기타 가이드` | 기타 가이드 |

이 8개가 전부입니다. **여기 없는 섹션이 필요하면 개발자에게 요청해 주세요**
(직접 선택지를 만들면 그 줄은 사이트에 나오지 않습니다).

---

## 3. 공개 / 숨기기

`상태` 칸만 바꾸면 됩니다.

| 상태 | 사이트에서 보이는 모습 |
|---|---|
| **공개** | 카드를 누르면 가이드 이미지를 크게 보는 페이지로 들어감 |
| **오픈예정** | 카드는 보이지만 「오픈 예정」 뱃지가 붙고, 눌러지지 않음 |

아직 준비 중인 가이드는 **오픈예정**으로 두세요. 줄을 지울 필요 없습니다.

`공개`라도 **`이미지` 칸이 비어 있으면 카드가 눌러지지 않습니다.** 열어봐야 볼 게
없기 때문이에요.

---

## 4. 순서 바꾸기

`순서` 칸에 숫자를 넣습니다. **작은 숫자가 위**로 갑니다.

```
멜론   → 순서 1
지니   → 순서 2
벅스   → 순서 3
```

노션에서 줄을 위아래로 드래그하는 건 **사이트 순서에 영향이 없습니다.**
노션 화면에서만 움직이는 거라, 반드시 `순서` 칸의 숫자를 고쳐주세요.

> 배너 DB는 반대로 「줄 순서」가 곧 화면 순서입니다. 헷갈리지 마세요.

---

## 5. 제목 바꾸기

**괜찮습니다.** 오타를 고치거나 이름을 다듬어도 됩니다.

가이드 하나하나는 공유할 수 있는 자기 주소를 갖습니다.

```
https://…/guide/streaming/멜론-a1b2c3d
                          ^^^^ 제목    ^^^^^^^ 줄마다 자동으로 붙는 꼬리표
```

제목을 바꾸면 주소 앞부분이 같이 바뀌지만, **이미 공유된 옛 주소도 그대로 열립니다.**
뒤의 꼬리표로 찾아가기 때문이에요.

---

## 6. 줄을 지우고 다시 만들지 마세요

**이게 이 문서에서 제일 중요합니다.**

내용을 갈아엎고 싶을 때 「기존 줄을 지우고 → 새 줄을 만들어 → 칸을 똑같이 채우는」
방식은 겉보기엔 같아 보이지만 **다른 가이드가 됩니다.** 주소 뒤의 꼬리표가 줄마다
자동으로 생기는 값이라, 새로 만들면 새 꼬리표를 받거든요.

그래서 이런 일이 생깁니다:

- 공지·SNS·카톡으로 **이미 공유한 가이드 링크가 「페이지를 찾을 수 없음」**이 됩니다
- 사이트 안에서 그 가이드로 걸어둔 바로가기(할 일 목록의 「가이드 보기」)도 끊깁니다

**대신 이렇게 해주세요.**

| 하고 싶은 일 | 이렇게 |
|---|---|
| 이미지를 새 버전으로 | 기존 줄을 열어 `이미지`만 교체 |
| 이름을 바꾸고 싶다 | 기존 줄의 `제목`만 수정 |
| 잠시 내리고 싶다 | `상태`를 `오픈예정`으로 |
| 아예 없애고 싶다 | 줄 삭제 (이건 괜찮습니다 — 되살릴 게 아니라면) |

줄을 **새로 추가**하는 건 얼마든지 괜찮습니다. 문제가 되는 건 「지우고 같은 걸 다시
만드는」 경우뿐이에요.

---

## 7. 이것만은 하지 말아 주세요

아래 세 가지는 사이트의 가이드 페이지가 **통째로 안 나오게** 만듭니다.
헷갈리시면 개발자에게 먼저 물어봐 주세요.

| 하면 안 되는 것 | 왜 |
|---|---|
| 칸(속성) 이름 바꾸기 — `제목`, `섹션`, `상태`, `이미지` 등 | 사이트가 이 이름으로 내용을 찾습니다 |
| `섹션`·`상태` 드롭다운 **선택지 이름** 바꾸기 | 어느 페이지에 넣을지, 공개할지 판단하는 기준입니다 |
| 「가이드」 DB 자체를 삭제하거나 다른 곳으로 옮기기 | 연결이 끊어집니다 |

위 셋은 DB의 *구조*를 바꾸는 일이라, 줄 하나를 고치는 것과는 다릅니다.

## 안 될 때 확인할 것

**이미지를 바꿨는데 사이트가 그대로예요**
→ 5분 기다린 뒤 새로고침해 보세요. 그래도 안 되면 브라우저에서
   강력 새로고침(`Ctrl`+`Shift`+`R`, 맥은 `Cmd`+`Shift`+`R`)을 해보세요.

**가이드가 아예 안 보여요**
→ `상태`가 **공개**인지, `섹션`이 비어 있지 않은지 확인해 주세요.
   둘 중 하나라도 비면 사이트에 나오지 않습니다.

**카드는 보이는데 눌러지지 않아요**
→ `상태`가 `오픈예정`이면 정상입니다. `공개`인데도 안 눌리면
   `이미지` 칸이 비어 있는지 확인해 주세요.

**공유한 가이드 링크가 「페이지를 찾을 수 없음」이 떠요**
→ 그 줄을 지웠다가 다시 만드셨을 가능성이 큽니다([6번](#6-줄을-지우고-다시-만들지-마세요)).
   개발자에게 알려주시면 새 주소를 안내해 드릴게요.

**그래도 이상해요**
→ 개발자에게 알려주세요. 노션 내용은 그대로 두시면 됩니다.
