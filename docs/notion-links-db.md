# 홈 바로가기 노션 DB 스키마 (개발자용)

홈 상단 배너 바로 아래의 **바로가기 아이콘**(투표 · 스트리밍 · 라디오 신청 · 폼 …)을
노션에서 관리하기 위한 설계 문서. 연결(Connection) 만들기 · 토큰 발급 · 데이터 소스
개념은 [notion-guide-db.md](./notion-guide-db.md)의 「노션 셋업 절차」와 동일하므로
여기서는 바로가기 DB에만 해당하는 내용을 적는다.

- DB URL: `https://app.notion.com/p/3b78b57d7cf48008a77bde1086708a75?v=…`
  (「메인화면 바로가기 링크」 페이지 안의 **인라인 DB**)
- 코드: `lib/notion.ts`의 `getQuickLinks()` → `lib/content.ts`의 `getQuickLinks()`
  → `app/page.tsx`

## DB 속성 정의

| 속성명 | 타입 | 용도 |
|---|---|---|
| `버튼 이름` | 제목(Title) | 아이콘 아래 표시되는 글자 |
| `emoji` | 텍스트(Rich text) | 아이콘 자리에 들어가는 이모지 하나 |
| `URL` | URL | 눌렀을 때 가는 곳 |
| `순서` | 숫자(Number) | 화면에 나오는 차례. 작은 수가 앞 |

`버튼 이름` 이나 `URL` 이 비면 그 행은 화면에 나오지 않는다(버튼을 만들 수 없을뿐더러,
노션이 기본으로 만들어 두는 빈 행이 여기서 함께 걸러진다). 바꿔 말해 **행을 지우지
않고 `URL` 만 비워 두면 임시로 내릴 수 있다.**

`emoji` 만 비면 버튼은 그대로 나오고 아이콘만 🔗 로 대체된다.

### `URL` — 사이트 안 · 밖을 자동으로 가른다

판단은 사이트 공용 규칙(`lib/url.ts`의 `resolveHref()`)이 하고, 렌더링은
`<SmartLink>`가 한다. 이 DB만의 규칙이 아니라 **사이트의 모든 링크가 같은 규칙**이다.

| 적는 값 | 동작 |
|---|---|
| `/oneclick/voting` | 사이트 안 이동 (`next/link`, 새로고침 없음) |
| `https://forms.google.com/…` | 새 탭으로 열림 |
| `tinyurl.com/xxxx` | `https://` 를 코드가 붙여서 새 탭 |
| `oneclick/voting` | 맨 앞 `/` 를 빠뜨린 것으로 보고 내부 경로로 고친다 |
| `javascript:…` · `//evil.com` | 각각 무시 · 외부 링크로 처리 |

## 순서

`순서` 숫자 열이 있으면 그 값, 없으면 **노션에 행을 추가한 순서**(먼저 만든 것이 앞).

> **노션에서 줄을 드래그해도 사이트 순서는 바뀌지 않는다.** 노션 API 는 뷰의 수동
> 정렬을 노출하지 않는다 — 행 객체에 순서 필드가 없고, `sorts` 를 생략하면
> `created_time` **내림차순**(최근에 만든 행이 맨 위)이 된다. 새 행을 아래에
> 추가하는 보통의 쓰임에서는 화면과 정확히 반대다. 그래서 `lib/notion.ts` 의
> `queryRows()` 가 오름차순을 명시한다.

`순서` 열은 있으면 쓰고 없으면 무시하므로, 만들고 지우는 데 코드 수정이 필요 없다.
값을 비워 둔 행은 맨 뒤로 간다.

점검은 `node scripts/notion-check.mjs` — 지금 화면에 어떤 순서로 나가는지,
`순서` 열이 비어 있지는 않은지 알려준다.

## 화면 배치

`grid-cols-3` (모바일) · `sm:grid-cols-5` (그 이상). 버튼 개수에 제한은 없지만
**5개 또는 3의 배수로 맞춰야 줄 끝이 비지 않는다.**

## 환경변수

```sh
NOTION_TOKEN=ntn_xxxxxxxxxxxxxxxxxxxx        # 가이드 · 배너 · 스밍리스트와 같은 토큰
NOTION_LINKS_DB_ID=3b78b57d7cf48008a77bde1086708a75
NOTION_LINKS_DS_ID=3b78b57d-7cf4-805b-a81e-000b268c08e5   # 선택: 요청당 왕복 한 번을 아낀다
```

이 DB는 인라인이므로 연결(Connection)은 **DB 자신 또는 DB가 들어 있는 페이지**에
붙인다. 권한은 위에서 아래로만 흐르므로, 페이지에 붙이면 그 페이지 안의 다른 것까지
토큰에 열린다 — 노출 범위를 좁게 두려면 DB 쪽에 붙이는 편이 낫다.

연결을 빠뜨리면 API가 404를 반환하고 **바로가기 섹션이 제목째 사라진다**
(서버 로그에 `[quick-links] 노션 조회 실패` 가 찍힌다). 코드에 기본값을 남겨두지
않은 이유는 `lib/site.ts` 주석 참고 — 노션에서 지운 버튼이 되살아나면 운영진이
손쓸 방법이 없기 때문이다. 헤더 내비게이션으로도 같은 곳에 갈 수 있어서
섹션이 잠깐 비어도 길이 막히지는 않는다.

반영 주기는 ISR 300초 (`app/page.tsx`의 `revalidate`).
